# Dracula Syntax Theme

A dark syntax theme for Atom based on the Dracula color scheme.

![Dracula Theme](https://user-images.githubusercontent.com/378023/49132477-f4b77680-f31f-11e8-8357-ac6491761c6c.png)

## Install

This theme is bundled with Atom and can be activated by going to the _Themes_ section in the Settings view (`cmd-,`) and selecting "Dracula Syntax" from the _Syntax Theme_ dropdown menu.

## Customize

It's still possible to modify theme styles. This theme uses LESS but you can override it with custom CSS. For example:

```css
.editor {
  .syntax--keyword {
    color: #ff79c6 !important;
    font-weight: bold;
  }
}
```
